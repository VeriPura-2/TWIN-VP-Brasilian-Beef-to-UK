01 Pre-contract & establishment eligibility Brazil ›
Key documents: GB approved establishment list (Defra XLSX), APHA topical issues check, MAPA SIGSIF export eligibility confirmation, SIF registration certificate, HACCP documentation
Compliance layer
Automated check of live Defra establishment list — confirm SIF number is active and product-approved. APHA topical issues feed scanned for current suspensions or RASFF alerts. Result: go / no-go before order is placed.
Visibility layer
Transaction record created on TWIN platform. Establishment eligibility status made available to relevant stakeholders (importer, insurer, buyer). Audit trail begins.
02 Commercial agreement & purchase order Brazil / GB ›
Key documents: Commercial contract / purchase order (HS code 0201 or 0202, age category, VC status, hormone-free requirement), product specification sheet, letter of credit
Compliance layer
Commercial contract ingested at intake. Product spec mapped to applicable regulatory requirements — age category triggers VC/SRM rules, hormone-free flag triggers SISBOV segregation requirement. Document profile built for the transaction.
Visibility layer
Transaction linked to importer and exporter DID identities on TWIN. Commercial parameters (product type, volume, route) logged as structured metadata.
03 Brazilian export certification: production & slaughter Brazil — SIF establishment ›
Key documents: SISBOV cattle traceability records, farm health declaration, ante-mortem & post-mortem inspection records, SRM/VC removal declaration (>30 months), temperature logs, residue test results (PNCRC/PNPR), microbiological test results, packaging & labelling records
Compliance layer
SISBOV farm-of-origin data ingested. Age verification checked — triggers mandatory SRM/VC removal pathway if >30 months. Residue test results parsed against MRL thresholds (estradiol-17β, zeranol, trenbolone, melengestrol). Cold chain logs monitored. Deforestation risk screening via MapBiomas/PRODES cross-reference.
Visibility layer
Supply chain trace path recorded on TWIN. Farm-of-origin linked to transaction record. MAPA OV inspection attestation logged as a signed event — verifiable by downstream parties without contacting MAPA directly.
04 Export Health Certificate (EHC) issuance Brazil — DIPOA certification centre ›
Key documents: EHC 7060EHC Part I (trade/identification data) and Part II (12 health attestations inc. hormone-free, SRM/VC, BSE, FMD, microbiological, residue compliance) — current model version, wet MAPA OV signature and official DIPOA stamp required. Certificate of Authenticity if TRQ 05.4453 (grass-fed quota) claimed.
Compliance layer
EHC Part I fields extracted and mapped to transaction profile (SIF number, lot numbers, HS code, weight, CHED reference). Part II attestations parsed — each of the 12 attestations flagged present/absent/partial. Model version checked against current APHA published list. Weight cross-checked against commercial invoice and packing list.
Visibility layer
EHC issuance event recorded on TWIN as a signed attestation. EHC reference, lot number, and SIF number committed to transaction record. SHA-256 hash of verified EHC anchored to IOTA Rebased L1 via Verifiable Credential (IOTA Identity 1.7).
05 Brazilian export clearance Brazil — SISCOMEX / customs ›
Key documents: Registro de Exportação (RE) — electronic export licence via SISCOMEX, Nota Fiscal Eletrônica (NF-e) — electronic tax invoice
Compliance layer
RE and NF-e ingested. NCM/HS codes cross-checked against commercial contract. Export licence validity confirmed. Documents added to transaction evidence bundle.
Visibility layer
Brazilian export clearance status recorded on TWIN. Transaction record updated — consignment confirmed in transit.
06 Shipping & commercial documentation Brazil / Ocean ›
Key documents: Commercial invoice, packing list (must match EHC exactly), Bill of Lading (container and seal numbers), container temperature log / reefer data logger printout (continuous), reefer certificate, container seal certificate
Compliance layer
Packing list numerically cross-checked against EHC Part I (weight, lot numbers, carton count). Seal number extracted from B/L and recorded for later identity check matching. Cold chain logger data ingested — temperature maintained against regime (≤+7°C fresh / ≤-18°C frozen). Any exceedance flagged as a compliance failure.
Visibility layer
Cold chain integrity status visible to permissioned stakeholders in real time during transit. Seal number and B/L reference linked to transaction record. Continuous temperature data available to insurer and buyer.
07 UK pre-arrival notification & import licensing GB — IPAFFS / RPA ›
Key documents: IPAFFS pre-notification (CHED-P) — mandatory, minimum 1 working day before arrival. CHED-P reference must appear in EHC Part I. TRQ Import Licence (Rural Payments Agency) and MAPA Certificate of Authenticity if quota 05.4453 claimed.
Compliance layer
CHED-P reference cross-checked against EHC Part I Box I.2. Pre-notification timing confirmed compliant (≥1 working day before arrival). TRQ licence validity and quota availability checked if applicable. CHED status tracked through BCP check stages.
Visibility layer
Pre-arrival notification status available to APHA / Port Health Authority via TWIN — consignment expected, compliance pre-check completed. Key touchpoint for agency visibility ahead of physical arrival.
08 UK customs declaration GB — HMRC CDS ›
Key documents: UK Customs Import Declaration (CDS) — commodity code (HS 0201/0202), importer EORI, CHED-P reference (code CHD), TRQ licence if applicable, customs value declaration
Compliance layer
CDS entry cross-referenced: commodity code accuracy, declared weight matching packing list, CHED reference present, correct tariff treatment (in-quota vs MFN). Commodity code validated against UK Global Tariff. Any discrepancy flagged pre-clearance.
Visibility layer
Customs declaration status linked to transaction record on TWIN. Tariff treatment and duty outcome logged for importer and buyer records.
09 Border Control Post arrival checks GB — BCP (Liverpool, Grimsby, Tilbury, Hull, Heathrow) ›
Key checks: Documentary (100% — EHC authentication, CHED match, invoice/packing list cross-check, temperature records). Identity checks (risk-based — seal integrity, label inspection, temperature spot-check). Physical checks (1–10% — hormone residue sampling, antibiotic testing, microbiological sampling, organoleptic assessment for fresh beef)
Compliance layer
Pre-verified compliance signal delivered to BCP before consignment arrives — EHC parsed, CHED matched, cold chain confirmed, residue flags surfaced. APHA OV documentary check outcome ingested from IPAFFS. Physical/lab results uploaded and compared against thresholds. Any detention or rejection recorded as a compliance event.
Visibility layer
BCP check outcomes recorded as TWIN events — timestamped and linked to the CHED-P reference. Immutable audit log visible to permissioned parties (importer, insurer, buyer). This is the "game-changing" visibility touchpoint for Port Health Authorities flagged in TWIN's trials.
10 Post-BCP: movement & ongoing compliance GB — first destination ›
Key requirements: CHED-P accompanies consignment to first destination. 72-hour OV notification if VC-bearing cuts from >30-month animals. Full document set retained minimum 12 months and available for APHA/FSA audit on demand.
Compliance layer
CHED-P Part II completion (APHA clearance) confirmed and linked. 72-hour OV notification obligation flagged automatically for applicable consignments. Compliance verdict (COMPLIANT / CONDITIONAL / NON-COMPLIANT) issued with full evidence chain and document reference index.
Visibility layer
Final compliance verdict and all verified document hashes committed to IOTA Rebased L1 via Verifiable Credential (IOTA Identity 1.7 / W3C VC spec). Gas Station sponsored — no token requirement for importer or exporter. Immutable record available for audit, insurance, and buyer due diligence.
11 Environmental & social compliance GB — ongoing ›
Key requirements: UK Environment Act 2021 Schedule 17 (Forest Risk Commodities — secondary legislation pending as of March 2026). Modern Slavery Act 2015 transparency statement. Brazilian CAR (Rural Environmental Registry) and SISBOV geolocation data for future deforestation due diligence.
Compliance layer
SISBOV farm GPS data cross-referenced against MapBiomas/PRODES deforestation databases. Preliminary risk score generated. CAR registry status checked. Modern Slavery Act obligation flagged for in-scope importers. Framework ready for Environment Act 2021 when secondary legislation is enacted.
Visibility layer
Environmental risk score and CAR compliance status visible to buyers and institutional clients via TWIN. VC structure aligned with emerging EU Digital Product Passport (DPP) framework for food commodities — future cross-border regulatory recognition pathway.
